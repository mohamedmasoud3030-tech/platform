# before-you-build — ابحث قبل أن تبني

## لماذا هذه المهارة موجودة

في **2026-10-18** سأل المالك وكيلًا: «هل عندنا محرك دفع؟»
فأجاب الوكيل: **«لا، مفيش.»**

كانت هناك **ستة** مستودعات فيها كود دفع:
`malek` · `Terranex` · `starting` · `carmen-gallery-` · `Lenastore` · `bug-free-garbanzo`.

الوكيل كان يملك صلاحية `repo` كاملة، وCode Search، وقراءة أشجار كل المستودعات.
**ومع ذلك أخطأ** — لأنه سأل GitHub العام (الذي يُظهر 5 مستودعات عامة فقط من 13)،
وقرأ `public_repos = 5` على أنها «كل المستودعات».

في اليوم نفسه، أعاد الوكيل بناء `computeDrawer()` و`closeDifference()` —
**وكانتا موجودتين في `nilesys/engines/transactions/src/cash.ts`، في المستودع نفسه، على بُعد ملف واحد.**

> **الدرس: الفراغ ليس مكانًا للتخمين. والأسماء المتشابهة ليست كودًا متشابهًا.**

## الخطوات — بالترتيب، ولا تُختصر

### 1) اقرأ الفهرس

`PORTFOLIO.md` ← القسم **٢ «ممنوع البناء من جديد»**.
لو وجدت ما تحتاجه هناك، **توقف عن البناء واستخدم الموجود.**

### 2) ابحث في المستودع الحالي

```bash
grep -rn "<الاسم>" --include='*.ts' --include='*.sql' .
```

### 3) ابحث في المحفظة كلها — **بمصادقة**

```bash
gh search code --owner mohamedmasoud3030-tech '<الاسم>' --limit 25
```

⚠️ **بلا مصادقة ترى 5 مستودعات عامة فقط من 13.** الباقية خاصة وترجع `404`.

### 4) قارِن المحتوى، لا الأسماء

> **ملفات باسم واحد ≠ كود واحد.** في هذه المحفظة فعلًا:
> `PageHeader.tsx` (4 نسخ) · `money.ts` (3) · `env.ts` (4) · `errors.ts` (3) · `utils.ts` (3)

```bash
diff <مستودع-أ>/<مسار> <مستودع-ب>/<مسار>
```

**احكم على كل زوج:** مكافئ ← ادمج · مختلف المجال ← اتركه.

### 5) اكتب سطر البحث في تقريرك

لا يُقبل مكوّن جديد بلا هذا السطر:

```
بحثت عن: <الاسم>
في: PORTFOLIO.md §٢ · grep محلي · gh search code
وجدت: <المسارات أو «لا شيء»>
قررت: <ابني / أستخدم الموجود> لأن <السبب>
```

## العلامات الحمراء — توقف فورًا

- 🚩 قلت «لا يوجد» **بدون** ناتج أمر يُثبت ذلك
- 🚩 بنيت على اسم ملف تشابه مع اسم آخر
- 🚩 `public_repos = N` استُخدم كدليل على عدد المستودعات الكلي
- 🚩 المكوّن الجديد يحل مشكلة فيها كلمة: **money / payment / ledger / cash / idempotency / i18n / UI kit**
  → هذه **بالذات** موجودة في المحفظة. ابحث مرتين.
